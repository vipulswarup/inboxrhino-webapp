> InboxRhino gives developers and QA teams real inboxes for testing the emails their apps send: signup verification, OTP codes, magic links and password resets.
>
> Create an address on test.inboxrhino.in with one API call, trigger the email from your app, then make one more request that waits up to 180 seconds for the message. You can filter by subject or sender, and the response includes the parsed body. You don't need an SDK, since plain HTTP works from curl, Playwright, Cypress or any test runner. The docs include a quickstart, an OpenAPI reference, a Playwright guide and a Cypress guide.
>
> Real mail comes in through Cloudflare MX, so this is not a local SMTP sandbox. Your app's real sending path gets tested end to end. When an assertion fails, QA can open the actual HTML email in a sandboxed console viewer that blocks scripts, forms, popups and remote images.
>
> Inboxes are receive-only. InboxRhino cannot send, reply or forward as a generated address. Messages are kept for 30 days, and then their content, headers and attachments are deleted.
>
> Pricing is in Indian rupees (plus GST when paid checkout launches). The Free plan is live and comes with 11 active inboxes and 33 emails a month, which is enough to wire up one flow. Starter is free for now with an access code. Paid checkout for Starter, Growth and Scale is coming soon.

> Built in India by Argali Knowledge Services.

### Features

- Real MX inboxes on test.inboxrhino.in via Cloudflare Email Routing.
- REST API to create inboxes and list messages.
- Wait-for-message endpoint with up to 180 seconds of long-polling and subject and sender filters.
- Parsed message body returned in the API response.
- No SDK required: use curl, the OpenAPI spec, Playwright, Cypress, or another HTTP test runner.
- Sandboxed HTML email viewer blocks scripts, forms, popups and remote images.
- Receive-only by design; inboxes cannot send or forward messages.
- 30-day message retention followed by automatic deletion.
- Multi-user organisations are planned for Growth and Scale; those plans are not purchasable yet.
- INR pricing; GST will be added to paid plan prices when checkout launches.

### Four FAQs

**What does the free InboxRhino plan include?**

The live Free plan costs ₹0 and includes 11 active inboxes, 33 inbound emails per UTC calendar month, and one organisation user.

**Can an InboxRhino test inbox send or forward email?**

No. InboxRhino inboxes are receive-only. They cannot send, reply, or forward messages.

**How long can InboxRhino wait for a message?**

The wait-for-message API can wait up to 180 seconds in one request. It can filter messages by subject or sender.

**Can I buy a paid InboxRhino plan now?**

No. Starter is currently complimentary with an access code. Paid checkout for Starter, Growth and Scale is not open yet. Prices are listed in INR, and GST will be added when paid checkout launches.
